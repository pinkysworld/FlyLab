## Abstract

FlyLab is a computational workflow for auditing which inputs affect predictions from literature-parameterised network simulations. It combines provenance-gated evidence transformations, graph-degradation diagnostics, layer ablation and specification-family sensitivity. A finite-library invariant audit checks that inadmissible evidence is refused (56 of 102 rows), while permitted transformations retain source-distance labels. Graph controls report permutation probabilities and a descriptive median-gap tolerance; the latter is not a statistical equivalence test. Synthetic recovery cases, matched ablation references and a variance decomposition assess selected properties of the workflow. Evaluated on cuts of the MaleCNS v1.0 *Drosophila* connectome, dependence labels change with the extract: an imidacloprid prediction is composition-dominated on the sparse `named` cut but topology-dependent on the denser extracts examined, including a smaller one. These observations show that node count alone cannot order the labels; they do not isolate recurrence as the cause. A composition-only baseline closely tracks the full model under shared assumptions, while nicotinic suppression reverses under monotone gain rules. The core pipeline recomputes committed-cut analyses; the large-scale table imports a saved study, and browser/server tests establish endpoint parity separately. Results concern model behaviour, not animal responses. Gain rules remain asserted, expression mapping coverage is 0.205 with MN9 unresolved, and independent circuit-level validation is absent.

**Index terms:** computational method, scientific software, provenance, evidence typing, network simulation, null models, tolerance diagnostics, multiple comparisons, specification robustness, sensitivity analysis, reproducible research, connectomics.

## 1. Introduction

A large class of scientific software has the same shape: a measured network, a table of parameters compiled from published literature, a rule that turns those parameters into perturbations of the network, and a numerical runtime that produces a prediction. Power grids, metabolic models, epidemic contact networks and connectome simulations are all built this way. Such a pipeline readily produces a number; what it does not produce is an answer to the question a reviewer asks first: *which of its inputs does this number actually depend on?* Without that answer the prediction cannot be audited, because a result carried entirely by an asserted coefficient is indistinguishable, at the output, from one carried by the measured structure.

Three properties make the question hard to answer in practice. The parameters are heterogeneous: sources measure different quantities, in different preparations, and are often simply absent, so a pipeline that coerces them into one numeric field silently manufactures evidence. The network enters through a runtime whose own conventions (normalisation, sign and iteration) are modelling choices that can carry part of the answer. And the usual test of whether structure matters is a permutation against a shuffled network, whose *non-rejection* is routinely written up as though the shuffle had reproduced the effect.

This paper contributes a method addressing all three (§2), an implementation that runs it per prediction rather than once per paper, and an evaluation of the instruments themselves (§3), the element we find missing from this literature. We demonstrate the method on cuts of a public synapse-resolution *Drosophila* connectome, a domain supplying exactly the hard case: a measured network, a literature parameter table with large gaps, and asserted transformation rules. The headline finding is about the method rather than the domain: **a dependence verdict obtained on one extract of a network can invert on another extract of the same network.**

We organise the work around four research questions.

* **RQ1.** Can heterogeneous published parameters be turned into computational perturbations *without* erasing their provenance or their parameter semantics, and can that discipline be stated as a checkable invariant rather than a convention?
* **RQ2.** For a given prediction, which inputs does it depend on, and is that answer a property of the prediction or of the extract of the network on which it was measured?
* **RQ3.** Which conclusions survive alternative admissible specifications, and which assumptions dominate the output's variance?
* **RQ4.** Which analyses can be recomputed from committed inputs, and what do backend parity checks establish?

The results support evidence gating and finite regression checks for RQ1. For RQ2, dependence labels vary with the extract as well as the prediction and analysis settings, including runtime normalisation. For RQ3, some conclusions reverse under admissible specifications. For RQ4, the core committed-cut analyses are recomputable and route-level parity is tested, while the scale study remains a cached exception. An earlier version of this work answered RQ2 with "most predictions do not need the network", measured on a single extract; this revision withdraws and explains that conclusion.

### 1.1 Related work and what is new here

**Network runtimes without parameterised perturbation.** The implemented teaching simulators RatCVS and Virtual Rat Web [1], [2] model dose–response with no network; PharmVR [3] is a non-peer-reviewed concept paper and is not evidence of an implemented capability. At the other extreme, FlyWire [4] and MaleCNS v1.0 [5] publish netlists with per-node annotations [9], [11]; Shiu *et al.* [6] show a literature-parameterised model over such a netlist reproduces a sensorimotor control, while an informal newsletter essay catalogs downstream ports with varying rigour [10]. FlyBrainLab [67] builds executable circuits directly from connectome data. The cited implementation does not describe the per-row pharmacological evidence gating evaluated here.

**Parameter-map-informed network models.** The closest published relatives simulate intervention on human structural connectomes by scaling regional responses with PET density maps [68], [69]. In Mindlin *et al.* [68], the simulated improvement tracked the *mean* density of the activated receptors rather than where they sit. Methodologically, §2.4 is a multiverse analysis [73], [74] applied to a simulation, and §2.6 uses Saltelli cross-sampling [70] with Jansen estimators [71] validated on Ishigami [72] and ranked by value of information [75].

**The domain evidence base.** The parameter library, and the supporting datasets for resistance alleles, expression, mixtures, exposure and behavioural endpoints, are compiled from the insect-versus-vertebrate pharmacology literature [7], [8], [12]–[66] and documented in §S4 and §S6. What matters methodologically is that the library is typical of such tables: incomplete, heterogeneous in what each source measured, and internally inconsistent with its own citations in ten places that `data/literature/README.md` records without editing the library to match. Those gaps make evidence gating affect numerical outputs.

**Position.** Table I states what is new narrowly. The transferable part is not the domain coupling but the instrumentation around it: routine per-prediction diagnostics combining provenance, graph degradations and specification checks. Synthetic recovery tests are an initial instrument evaluation. A median-distance tolerance is distinct from statistical equivalence, and multiplicity guarantees depend on the assumptions of the adjustment.

## 2. Methods

### 2.1 Typed evidence propagation (RQ1)

The common failure this replaces is a pipeline that applies one transform to whatever number a source reported and gives the result one name. That erases two distinctions at once: a normalised functional response is not a fraction of occupied binding sites, and a row with no sourced number must not yield a small response at all.

Each row records the **parameter type** its source measured and an ordered **evidence distance** from the modelled target: E0 (on-target); E1 (cross-species); E2 (related receptor); E3 (class extrapolation); E4 (unsupported). The admissible transformation is a total function of that pair (T20). Example legal triples are `(Kd, E0, binding_occupancy)`, `(Kd, E1, binding_engagement_proxy)` and `(EC50, E0, functional_engagement)`; transferred functional potencies use `functional_engagement_proxy`, while any E4 row is `not_modelled`. An attempted `(EC50, E0, binding_occupancy)` transformation raises `EvidenceTypeError`. Every numeric branch retains the same Hill algebra, `C^n/(x^n + C^n)`: the exact *Drosophila* Kd row licenses a binding-occupancy label but introduces no new kinetic binding model.

The enforceable invariant is narrow: *no numeric engagement reaching a readout may originate from a row whose (parameter type, distance) pair does not admit one*. A finite regression audit exercises every shipped row through the enumerated comparison, curve, uncertainty, assay and dashboard paths, checks that dropping inadmissible rows changes no gain vector, and verifies deliberate invalid requests. This is coverage of the shipped library and enumerated paths, not proof about an unenumerated future entry point.

### 2.2 The extracts, and what the runtime does to them

Two committed extracts of MaleCNS v1.0 are used, streamed out of the ~1.1 GB public weight matrix on a CI runner and each under about 1 MB of JSON: **`named`**, a 1-hop neighbourhood of two named cell types (four seed cells) (1126 nodes, 1360 edges), and **`taste_motor`**, the same seeds plus sensory types and an induced closure (1841 nodes, 19 066 edges). §3.2 adds a ladder of nested extracts of 1k, 5k, 10k, 25k, 50k cells grown by one fixed rule.

**The extracts are structurally very different, and the difference turns out to be load-bearing (T19).** `named` has mean degree 1.208: 85% of its edges terminate on the 4 seed cells, only 184 of 1126 nodes receive any input, and only 25% of edges leave a node that itself receives input. It is dominated by incoming edges to seeds, with limited recurrent connectivity. `taste_motor` has mean degree 10.4, 10% of edges onto seeds and 97% of edges leaving a node with input. Composition differs too, and octopamine is absent from both (0 cells), so a perturbation acting only through it cannot move either readout for substrate rather than domain reasons; the full census is in T19 and §S9(v).

Two runtimes consume a gain patch: a deterministic clipped leaky rate iteration (~50 ms per evaluation of `named`) and a current-based LIF network [6] whose synaptic scale and background drive are tuned constants, not fits (§S3).

**The rate runtime row-normalises its weight matrix, and previous versions of this paper did not say so.** Each row of the signed matrix is divided by `max(Σ|W|, 1)` before any gain is applied, and gains then act as a presynaptic column scale, so every node's recurrent input is a *composition-weighted average of its presynaptic gains*. That builds part of the answer to RQ2 into the readout itself; an example of the general hazard that a runtime convention can carry a result; so it is documented here, in T2 and §S3, and swept in §3.3 against `none` and a degree-corrected denominator. The sign table the runtime iterates is published as T21: 5 of seven magnitudes (glutamate -0.4, histamine -0.5, dopamine +0.2, serotonin +0.2, octopamine +0.2) are asserted, varied by no member of the specification family and not bounded by the label-permuting null.

### 2.3 Input-dependence testing (RQ2)

The instrument we consider most transferable asks, for one `compound × concentration × circuit × readout`, how much of the real connectome a prediction needs. The same drug contrast (treated minus vehicle, both arms on the *same* graph) is measured on progressively degraded copies of the cut, which form an **information ladder**:

| Graph model | What it still knows |
|---|---|
| `erdos_renyi` | node and edge counts, the weight histogram, the transmitter census |
| `rewire_degree_preserving` | + every node's in-degree, out-degree and transmitter |
| `weight_permute` | + the real edge list (weights reshuffled) |
| `sign_permute_weight_matched` | + the real weights on the real edges, and each transmitter's share of total outgoing weight |
| the MaleCNS cut | everything |

The rank-3 rung changed in this revision. Because a gain patch acts *through* transmitter identity, a null that moves the weighted balance moves the drug's target set and the sign matrix at once, so the plain label permutation is relabelled a **joint target-set-and-sign null** and replaced by a constrained shuffle holding every tracked transmitter's share of outgoing weight within 0.002 of the real graph's. Permuting the node transmitter-label array preserves the transmitter histogram *by count* but not *by weight*: out-strength is heterogeneous, so on the `named` cut the cholinergic share of total outgoing synaptic weight is 0.619 on the real graph against 0.544 ± 0.027 across 1000 permutations, putting the real graph at the 100th percentile of its own null (T23).

**Non-rejection and a small median gap are descriptive diagnostics, not an equivalence test.** Each mode is first assessed with the empirical two-sided permutation probability `(k+1)/(n+1)`. If it is not rejected, the implementation compares the absolute gap between the real effect and null median with a configured tolerance of 5% of the real graph's vehicle readout (0.332 rate-model units on `named`). The legacy label `equivalent_within_tolerance` means only that this point-gap criterion passed; it does not test whether an uncertainty interval lies within equivalence bounds or whether typical shuffled graphs are close enough. The remaining non-rejections are `indeterminate`. Classes and the legacy **necessary information level** are descriptive summaries of these diagnostics, not proofs of necessary or sufficient input information. The nulls are not nested, so an earlier non-rejection can coexist with a later rejection.

Three further conventions are fixed in the implementation and §S2 states them in full: a *relative* effect floor, a separation of detailed reference profiles from library-wide screens, with Benjamini-Hochberg applied across the screens' component structural tests, and a check of how many tests sit at the resolution floor, so resolution limitations remain visible. A cell is then labelled topology-dependent if either adjusted structural test rejects. The adjustment therefore applies to the component tests; it is not a demonstrated cell-level FDR guarantee, and reuse of shuffle draws does not by itself establish the dependence condition required for the usual Benjamini-Hochberg guarantee. These conventions were refined during iterative analysis, not externally registered before results were inspected.

### 2.4 The ablation ladder and the specification family (RQ3)

*Which layer carries the information?* Four models predict the same cell with one layer denied: **A** receptor engagement alone; **B** mechanism gains on the graph's transmitter composition only, no edges; **C** the real cut and runtime with one generic multiplier; **D** the full model. They carry different units, so they are compared by how well each reproduces the full model's *ordering* of the library, scored on the **signed** Spearman ρ because a perfect inversion reproduces nothing.

Level C's multiplier changed in this revision: it could previously only *depress*, so no entry could come out positive and the level could not order a library half of whose entries raise the readout. Its magnitude is unchanged and its **sign** now comes from the mechanism table; one bit per compound; with the old rule retained as a floor (§S1). Levels B and D are not independent models, both being functions of the same gain vector, so §3.3 reports a **matched reference distribution** saying what agreement would have been for structural reasons alone.

*Which conclusions are properties of the data rather than of a modelling choice?* The parameter-to-gain mapping is the least defensible part of the pipeline; a textbook shape, but an asserted functional form. We evaluate a fixed family of 25 admissible specifications (five shapes at five coefficient scales, §S1.1) and re-derive every principal conclusion under every member; undecidable cells count against the conclusion and are reported separately, and the fraction is a fraction of *that family*, not a posterior probability. The topology conclusions are decided at 100 permutations per specification (resolution 0.010), using Benjamini-Hochberg-adjusted component probabilities across the run's 100 structural tests. This does not supply a conclusion-level FDR guarantee. The two thresholds are likewise conventions, so the verdict is recomputed over the full 25%, 40%, 50% × 10%, 20%, 30% grid on 10 compounds.

### 2.5 Evaluation taxonomy

Agreement with published work is worth little unless its kind is named, so we separate three. **Implementation consistency**; the same inputs give the same outputs across transports, runtimes and runs (§3.7). **Literature concordance**; the model's *ordering* agrees with a published ordering, scored per entry and never as a bare mean, since an entry ordering two items can only return ±1; where the published ordering shares a source with the library, agreement is internal consistency, and the pipeline computes that overlap from DOIs and PMIDs rather than asserting it. **Independent out-of-sample validation**; against data entering neither the library nor the model, of which there is **none** at the circuit level. The synthetic experiment of §3.1 assesses selected instrument behaviours. It neither establishes general calibration of the instrument nor validates the domain model.

### 2.6 Global uncertainty and the value of information

A one-at-a-time tornado cannot separate a factor's own effect from its interactions, so uncertainty is attributed with a variance-based (Sobol') analysis over selected assumptions the implementation exposes; potency, Hill coefficient, the engagement-to-gain transformation and its coefficient, the external drive, the cut's synapse-weight threshold, the transmitter-sign convention, the expression-weighting layer; plus a deliberately null factor, the spiking RNG seed, which the deterministic rate engine ignores. The design is Saltelli cross-sampling with Jansen estimators [70], [71], validated against the analytic Ishigami benchmark [72] in the same run.

Estimates are left unclipped, so a factor whose true index is zero can be estimated below zero. A first-order index cannot be negative, so the **largest magnitude among the negative estimates is a measured lower bound on the estimator's error**, and we report it as an error diagnostic, not a calibrated noise floor or universal bound. The budget becomes a ranking by `VOI_j = max(0, S_j) · Var(Y)` [75]; variance of a model output under assumed input ranges, not an expected gain in accuracy about a living fly.

## 3. Results

This section evaluates the instruments, not the domain. Core committed-cut values are generated by `scripts/reproduce_paper.py` and stored keyed in `papers/results.json`; T27 is imported from the cached scale study described in §3.7. The parameter library and demonstration readouts are described in §3.6 and §S6.

### 3.1 Synthetic recovery, detection frequency and convergence (Fig. F16, Tables T11, T22)

A negative from a dependence test is uninterpretable unless the test can return a positive when one exists, so the instrument is characterised against **planted ground truth**. A synthetic network with 250 nodes and 1500 background edges receives a recurrent cycle of known strength. It is not matched in size or density to the real extract. The imposed motif makes the drug contrast depend on wiring by construction. Strength 0 omits both the cycle edges and their associated transmitter relabelling, so it is an unplanted control rather than a perfectly matched zero-strength intervention.

The ladder recovered 2 of 3 planted effects at *n* = 200 with no detection in its unplanted control. The detection grid uses only 6 generated networks per cell and permutation counts 50, 200, 1000: rates by strength are strength 0.25: 0.00-0.17; strength 0.5: 0.67-0.83; strength 1: 1.00-1.00, with all sampled runs detected at 1 and low detection at 0.25. These are observed frequencies, not precisely estimated power or type-I-error rates. The unplanted control has 0 detections in 18 runs. Reuse of networks or shuffle prefixes across settings also limits independent replication. Detection by permutation count is n=50: 0.61, n=200: 0.61, n=1000: 0.67; this small experiment does not justify a general rule that more shuffles are wasteful, nor establish adequate power for the real taste-motor veto-ratio endpoint. Weak planted effects are often missed, so non-rejection cannot rule out structure dependence.

The prefix sweep (T11) distinguishes label agreement from probability precision. Observed labels remain unchanged from *n* = 50–400, while probabilities first remain within ±0.02 of their final estimates after 25–400 draws. These are descriptive comparisons with the final estimate, not confidence bounds on the true permutation probability. Prefixes reuse the same draws and are not independent replications.

### 3.2 Dependence labels change with the extract (Figs. F6, F12; Tables T6, T12, T12b, T23, T27)

**The detailed reference profiles** (full per-mode table: T6, §S2.1). At 1000 permutations per mode (resolution 0.0010), imidacloprid's effect on the sparse `named` extract is -6.173 rate-model units and the cell is **composition-dominated**: against the configured tolerance of 0.332 rate-model units it passes the descriptive median-gap criterion for rewire_degree_preserving, sign_permute_weight_matched, weight_permute, merely indeterminate for sign_permute, and distinguishable only from the Erdős–Rényi control (*p* = 9.99e-04 against 0.472 for degree-preserving rewiring). Fipronil on the same extract is the contrast; 0.900 rate-model units, **topology-dependent**, *p* = 0.006 and 0.007 for weight permutation and rewiring, necessary level `wiring_with_weighted_transmitter_balance`; so the instrument separates two predictions on one extract. Constraining the transmitter null changes the ensemble and its probabilities: imidacloprid's gap from the null median falls from 2.652 rate-model units to 0.236 rate-model units, meeting the descriptive median-distance tolerance rather than establishing statistical equivalence.

**The landscape inverts between the two extracts.** Over 21 compounds × 4 concentrations = 84 cells at 1000 permutations, with Benjamini-Hochberg across the 168 component structural tests and the relative effect floor applied, `named` gives **11 topology-dependent, 42 composition-dominated, 31 no-effect, 0 mixed** (uncorrected 14 / 39 / 31; on the absolute floor alone 16 / 55 / 13, the 18 cells the relative floor removes named in T12). Repeated unchanged on the denser `taste_motor` extract at 300 permutations, the same 84 cells give **54 / 0 / 30**: every cell above the floor is topology-dependent, imidacloprid included (*p* = 0.003, adjusted 0.006, class topology-dependent). These are cell classes formed from adjusted component tests, not a cell-level FDR-controlled count; shared shuffle draws also leave the usual Benjamini-Hochberg dependence condition unverified.

**Extract structure is associated with the label, but recurrence is not isolated.** Across 7 examined extracts (scale_1k, named, taste_motor, scale_5k, scale_10k, scale_25k, scale_50k; T27), composition-dominated labels occur on 1 extract, `named`, and the inversion does not track the number of cells: `scale_1k` has 1000 nodes against `named`'s 1126 and a mean degree of 22.9 against 1.21, and it is already topology-dependent. This rules out a simple monotone relationship with node count in this example. It does not identify recurrence as the cause: construction, density, composition, paths, readout support and permutation effort also vary, and there is only one composition-dominated extract. The nested `scale_*` subset holds the extraction recipe fixed, not all these other properties. Its final two labels agree under the descriptive stability rule (§S2.4); this is not convergence to a whole-network verdict. At scale_5k, scale_10k all tested nulls are rejected. The imidacloprid relative effect spans 0.52-0.93 of vehicle, but similar aggregate magnitude does not make different extracts identical estimands.

Two honesty constraints travel with that result. The allocated permutation budget falls as the network grows (20-1000 draws, resolution 0.0010-0.0476), and at scale_10k, scale_25k, scale_50k the permutation budget falls to n = 20, where the smallest attainable probability is 0.048 against alpha = 0.05: a rejection there is the smallest the test can express; so the top-rung labels are resolution-limited observations, not independent confirmation of a settled verdict. Their probabilities are nominal and are not adjusted across the complete scale study. And the two hops-limited cuts are built by a different rule from the nested rungs, so comparisons *within* the ladder hold the construction recipe fixed while other graph properties still vary.

**What is supported.** The earlier generalisation that most model predictions are carried by composition does not survive a change of extract. The supported methodological result is narrower: a dependence label is conditional on the model, extract, readout, null family and statistical effort, and must be reported with those settings. The proposed recurrence explanation needs a controlled comparison that changes recurrent structure while holding other relevant properties fixed. The present comparison does not provide that causal test.

**Multiplicity sensitivity.** In the detailed reference profile, fipronil at 1 µM has a nominal result (*p* = 0.006 at *n* = 1000). Inside the exploratory landscape the same cell's adjusted component probability is 0.050 and no structural mode remains rejected; its adjusted-test class there is composition-dominated against an unadjusted topology-dependent.

**Two things the class label does not say.** The ladder is **non-monotone** in 11 of 84 cells on `named` and 0 of 84 on `taste_motor`, because adjacent rungs destroy different things; the level therefore means "the cheapest degraded input this test cannot tell apart from the real one", never "everything above it is indistinguishable too". And `composition-dominated` reports a failure to distinguish, never a reproduction: across the `named` landscape's mode verdicts, 281 pass the descriptive median-gap tolerance, 50 indeterminate and 89 distinguishable.

### 3.3 Which pipeline layer carries the information, and what agreement would have been anyway (Fig. F13, Tables T13, T13b, T24, T25)

Receptor engagement alone orders the library **backwards** (signed ρ -0.506 to -0.046) and is now the worst level at every concentration; constant across the table: yes (10 nM: A_receptor_only (-0.046); 100 nM: A_receptor_only (-0.348); 1 µM: A_receptor_only (-0.431); 10 µM: A_receptor_only (-0.506)). Under the historical level-C rule the worst level was *not* constant (10 nM: C_topology_only; 100 nM: A_receptor_only; 1 µM: A_receptor_only; 10 µM: A_receptor_only), so the previous claim that the topology-only level is the worst of the four was true of one column and false of the others.

**The ablation conclusion is withdrawn.** Level C's multiplier applied a depression-only factor to every transmitter, so every entry was at most zero and the level could not represent disinhibition. With a direction-aware rule using the same generic magnitude and one bit of sign, its rank correlation with the full model at 1 µM rises from 0.242 to 0.961. The sentence "the connectome without the pharmacology is not a cheap substitute for the connectome with it" was a statement about a sign-broken baseline and is retracted.

**The composition-versus-full correlation is influenced by shared assumptions.** It is 0.988 at 1 µM and 0.989 after dropping the compounds on the 0.05 gain floor, so it is not a tie artefact. But levels B and D are both functions of the same gain vector, and the matched reference says what would have been unsurprising: pharmacology-free pseudo-compounds with the gain shape the shipped rules produce give a median of 0.847 over 50 draws (5th–95th percentile 0.676 to 0.953). The observed correlation exceeds the reported reference 95th percentile, so this comparison does not establish that its entire magnitude is explained by shared algebra. Jointly permuting paired B/D labels leaves ρ = 0.988 unchanged by construction and is not an independence test. The reference is therefore a structural sensitivity comparison, not proof that compound-level information is absent.

**And it is not robust to the runtime.** The correlation is 0.988 under the shipped normalisation and 0.906 with none, but 0.666 under a degree-corrected denominator at 1 µM and -0.372 at 10 nM: it survives row_abs, none and not a degree correction, so it is a property of *this runtime's readout* as much as of the perturbation. A sign disagreement between the two levels moves it by at most 0.057 and so is not what produces the agreement (§S9(i)).

### 3.4 Specification robustness: which conclusions survive the modelling choices (Fig. F14, Tables T14, T14b, T15)

**The previous 25/25 topology result was vacuous, and the failure mode is general.** Two faults compounded. The matrix was computed at 6 shuffles per specification, where the smallest attainable permutation probability is 1/7 = 0.143, so `p ≤ 0.05` was arithmetically unattainable and the predicate silently fell back on a Gaussian criterion. And the specification context rebound the transformation on the assay modules but not on the engine the permutation path resolves, so **all 25 specifications fed default values to their nulls and produced identical effects**. A robustness matrix can thus report perfect stability because its alternatives never reached the code under test; a bug no determinism check can catch, since the run is perfectly reproducible either way.

Recomputed at 100 shuffles per specification (resolution 0.010), with the specification pushed into the null engine and Benjamini-Hochberg applied across the 100 component structural tests, C4 remains topology-dependent in 25/25 specifications: it is a thresholded rejection predicate, retained when at least one of the two adjusted structural tests rejects. C3 has no structural rejection in 25/25, unchanged from its 25 unadjusted retentions. Adjustment cannot strengthen this failure-to-reject conclusion: 17 pass the configured descriptive median-gap criterion and 8 are merely indeterminate. Under the 25 specifications:

* The claim that the agonist suppresses activity is retained by only 15 and **reversed** by all 10 monotone specifications: the same compound at the same engagement takes the network from 6.631 to 10.1 rate-model units (+52%) instead of from 6.631 to 0.458 rate-model units, with `g_ach` at 1.396 against 0.050. The direction is a property of one asserted term, not of the integration.
* A buffering claim is retained 18 of 25 and reversed by none, its 7 failures being undecidable. The previous claim that monotone rules buffer "at least as much, never less" is **false**: over the 6 reversing specifications with a defined index the mean gap runs -0.199 to -1.734 log₁₀ units, 3 buffer *less* (linear@1.50x, saturating@1.25x, saturating@1.50x), and the aggregate is carried by the extreme; an aggregate standing in for a range it does not represent.
* The matching amplification claim is weakest at 19 of 25. Retained by every specification: C2_rdl_disinhibition, C3_imidacloprid_topology_not_distinguishable, C4_fipronil_topology_exceeds, C7_map_bitter_veto.

The threshold grid makes the same point about conventions rather than transformations: the split is **not** stable (`stable = no`), buffering holding in 9 of 9 cells (-0.362 to -1.224 log₁₀ units) and amplification in 8 of 9, flipping at the strictest corner (circuit_frac=0.50,vert_limit=0.10, gap -0.075), so ranges are quoted and never the point estimate. T15 scores 10 compounds in two mechanism classes, while T8 scores the whole library, so acetylcholine is scored in one and outside the other's scope.

### 3.5 Variance attribution, and what to measure next (Fig. F15, Tables T16, T17)

The Sobol' analysis (11 264 model evaluations at n_base = 1024, Var(Y) = 3.149 squared rate-model units) resolves 2 of 9 factors in the strict sense of a bootstrap first-order interval excluding zero: gain_transform, weight_threshold; the **engagement-to-gain transformation** (S1 0.410, ST 0.626) and the cut's **synapse-weight threshold** (S1 0.294, ST 0.542). Everything else is unresolved at this sample size (drive, expression, gain_coef, hill_n, lif_seed, potency, transmitter), including the external drive, whose S1 of 0.019 sits below the largest observed negative-index magnitude of 0.046 on an interval of (-0.072, +0.112). This finite-sample diagnostic is set by gain_coef, not by the declared null factor `lif_seed` at -0.007; the previous version of this section quoted the null factor and then ranked a factor inside the resulting noise. The residual `1 − sum(S1)` is 0.344 raw and 0.272 with negatives clipped; estimator error contributes to this difference, so neither is a precise interaction fraction. On the analytic benchmark the estimator returns 0.3163, 0.4495, 0.0072 against the exact 0.3139, 0.4424, 0.0000 at n_base = 16 384 (max error 0.007).

The top factor is **gain_transform** (1.290 of 3.149 squared rate-model units), resolved by *calibration of receptor engagement against synaptic gain*; reading the *shape* of the response-versus-engagement curve at a known synapse, which is precisely the assumption §3.4 shows the suppression conclusion turns on. The second, **weight_threshold** (0.925 squared rate-model units), motivates re-analysis of synapse-confidence strata. Such analysis measures sensitivity to extraction choices; it does not resolve missing connectivity or guarantee the stated variance reduction in practice.

### 3.6 What the refusal rule actually does (Fig. F11, Tables T10, T20)

Evidence gating changes numerical outputs and their interpretation. Of 102 library rows, 56 carry no admissible evidence and return N/A instead of a small plausible number. Dispatch on the (parameter type, distance) pair assigns 1 row a physical binding-occupancy model, 1 a binding proxy, 9 a direct functional engagement and 35 a transferred one. The physical row is imidacloprid at insect_nAChR_native_dmel (Kd 2e-09 M) [76]; the previous binding constant, imidacloprid at insect_nAChR_beta1 (Kd 8.3e-11 M), is retained numerically but labelled as a cross-species proxy. Without the new exact-target row, the shipped library would have no example exercising the physical-occupancy branch. The finite audit makes that coverage visible; it does not introduce new Hill algebra. The full census, downstream domain readouts and literature-concordance analysis are in §S6 and §S10.

### 3.7 Reproduction, determinism and cross-backend parity (Fig. F1)

The standard command recomputes the core analyses on committed cuts and renders the paper. The scale table is an exception: it imports `papers/scale_study.json`, a committed earlier result, rather than recomputing the large-rung profiles. Only the smallest scale cut is committed; a fresh scale study requires the missing cuts and their upstream data. Re-rendering T27 is therefore not an independent reproduction of that experiment:

```bash
python -m pip install -e ".[dev,viz]"
python scripts/reproduce_paper.py          # full run
python scripts/reproduce_paper.py --fast   # reduced permutation and replicate counts
python scripts/reproduce_paper.py --only dependence --outdir /tmp/x
```

Beyond the paper, `flylab run` turns a declarative spec into a self-describing run directory whose manifest records spec, code and library hashes, seeds and two hashes per artifact; a dedicated test reproduces that spec-run artifact byte for byte (`docs/WORKFLOW.md`). For the paper pipeline, the determinism test repeats only the reduced provenance-and-census path, not every full analysis step. `papers/results.json` carries each quoted simulation value with its text, unit and producing step. The suite checks that quoted keys exist, the committed record is not reduced-effort, and the statistical parameters covered by the guard equal declared defaults.

The same wheel runs in a browser tab on Pyodide and is published as a static site, so these assays can be re-run by opening one link with nothing installed; `tests/test_browser_bridge.py` asserts **endpoint parity**; equal JSON, every readout, warning and provenance field, for a representative call to each route, which is route-level equality rather than a whole-analysis equality claim. ## 4. Discussion

**What transfers.** The observed labels change across extracts: 42 of 84 cells are composition-dominated on `named`, compared with 0 of 84 on `taste_motor`. T27 adds examples at different sizes, but only one extract carries the composition-dominated label and several structural statistics distinguish that extract simultaneously. Recurrence is a plausible explanation, not an isolated predictor or demonstrated cause. The practical lesson is to accompany dependence labels with extract structure, model conventions and statistical effort; a non-rejection on a sparse cut cannot establish that wiring is dispensable in the network it came from.

*Second*, typing the evidence changes results rather than documentation: refusing inadmissible rows removed a class of small, plausible, invented numbers no reader could have told apart from measurements, and grading a source's distance demoted a cross-species constant to a labelled proxy without changing its value. The invariant is enforced at transformation and audited over every shipped row through the enumerated readout paths; this is stronger than a documentation convention, while remaining a finite regression audit rather than proof about unenumerated future paths.

*Third*, two of the instruments were themselves broken in ways that flattered the conclusions, and both were found by pointing the instruments inward: a null that moved the quantity it claimed to preserve exactly, and a specification family whose alternatives never reached the engine its predicates ran on, so a uniform robustness rate was guaranteed by construction. Both failures share a signature worth naming; **an implementation that prevented the intended comparison**; and both were invisible to determinism checks, because a record can be perfectly reproducible and still be produced by a test that could not have returned another answer. The specification family and the variance decomposition then converge on one weak point: the direction of the headline effect is set by an asserted functional form, which is also the largest resolved factor in the variance budget and the top-ranked measurement.

**Encoded assumptions versus generated observations.** The separation is itself generated rather than asserted: an audit of the dependency chain behind one readout returns 9 links (T18), of which exactly 1 link is a measurement of the system being simulated, 1 reuses a measurement of something else, 4 are asserted modelling choices and 3 are arithmetic on the links above. A companion decomposition; a different decomposition, not a repartition of those links; reports 5 facts, 1 model inference and 5 unknowns. That one link in nine is a measurement of the simulated system is worth stating plainly for any pipeline of this shape.

**Relation to adjacent work.** Our version of the [68], [69] result survives neither a change of extract (§3.2) nor a change of the runtime's normalisation (§3.3), and both models normalise or regionally average, so the parallel is at least as consistent with a shared modelling artefact as with a property of receptor-weighted network perturbation. That is itself a methodological observation: a result reproduced across two pipelines that share a normalisation convention has not been independently confirmed.

**What the pipeline cannot support**, and these limits are themselves computing results about what such a pipeline can establish. It cannot predict a dose–response in an animal: with no pharmacokinetics available, the free concentration is an *input*, not a derived quantity. It cannot support a cross-species safety claim, nor a subunit-level claim where the sources used hybrid constructs. It cannot support a general statement about whether perturbation on networks of this kind needs topology; only a statement per extract with that extract's structure reported. And it cannot produce a live-animal result, which no code path may write.

**Five model-specific caveats** are given in full in §S9: an asserted sign table exempt from the specification family and unbounded by the label-permuting null; the load-bearing row normalisation; perturbations applied across transmitter-defined rather than receptor-defined synapses, which the expression layer bounds rather than corrects; hops-limited extracts with unobserved boundary inputs and extract-sensitive results; and agreement of direction only between the two runtimes.

**Prospective, not pre-registered.** The hypotheses in §S5 are written before any experiment and labelled as software predictions with no live result; a mutable repository is not a registry, and an archive DOI alone does not establish preregistration. A dated, frozen experimental protocol specifying hypotheses, outcomes and analyses before collection is also needed. Two of them predict a readout whose *sign* is a modelling choice over this paper's own specification family, and the supplement now says so beside them.

## 5. Conclusion

We set out to make a network simulation say which of its inputs its predictions depend on, and to evaluate that machinery rather than assert it. The method combines four components: typed evidence propagation under an enforced transformation rule and finite-library invariant audit, input-dependence diagnostics with an explicit point-gap tolerance and component-test multiplicity adjustment, an ablation ladder scored against a matched reference, and specification-family robustness with variance attribution; none specific to the domain we demonstrate them on. Pointed at its own results, the method establishes that the headline effect's direction is a property of an asserted functional form; that layer-agreement scores depend on shared gains and runtime normalisation; and that **dependence labels can change across extracts of the same network**. The present study does not isolate recurrence from correlated extraction properties. A "this prediction does not need the structure" result is only as good as the extract it was measured on, and structural summaries can flag the need for additional checks; they are not yet validated substitutes for those checks.

What would change the picture is short and specific, and the variance budget rather than taste names it: a calibration of the parameter-to-gain transformation at a known synapse; a reconstruction-confidence re-analysis, which needs no new measurement; a full landscape on an extract that is neither an in-star nor hops-limited; and one live assay. Until then this is a description of a method, and of a tool that tests itself.
