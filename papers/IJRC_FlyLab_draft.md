## Abstract

Literature-parameterised network simulations can report predictions without showing which inputs carry them. We evaluate a method combining typed evidence gates, graph-degradation nulls, a matched ablation reference, gain-rule specifications and variance attribution on two cuts of the MaleCNS v1.0 *Drosophila* connectome. The current 21-compound library has 102 parameter rows; 63 do not yield numerical engagement after unsupported sources are withheld. This is a syntactic admission rule, not proof that every admitted assay value is correct: source-to-parameter verification remains incomplete. The incoming-star-like `named` cut has 85% of edges entering four seed cells. Under the declared floors and adjusted component tests, its 84 compound–concentration cells have 0 topology-dependent and 44 composition-dominated descriptive labels, while the denser `taste_motor` cut has 44 and 0. This contrast illustrates extract sensitivity, not a causal effect of recurrence. The gain transformation controls the direction of one model-output predicate. The larger scale study is imported from a saved record, and no independent circuit-level biological validation is available.

**Index terms:** computational method, scientific software, provenance, evidence typing, network simulation, null models, permutation testing, multiple comparisons, specification sensitivity, reproducible research, connectomics.

## 1. Introduction

A large class of scientific software has the same shape: a measured network, a table of parameters compiled from literature and declared model assumptions, a rule that turns those parameters into perturbations of the network, and a numerical runtime that produces a prediction. Related pipelines occur in several scientific domains; this study tests one connectome application. Such a pipeline readily produces a number; what it does not produce is an answer to the question a reviewer asks first — *which of its inputs does this number actually depend on?* Without that answer the prediction cannot be audited, because a result carried entirely by an asserted coefficient is indistinguishable, at the output, from one carried by the measured structure.

Three properties make the question hard to answer in practice. The parameters are heterogeneous: sources measure different quantities, in different preparations, and are often simply absent, so a pipeline that coerces them into one numeric field silently manufactures evidence. The network enters through a runtime whose own conventions — normalisation, sign, iteration — are modelling choices that can carry part of the answer. And the usual test of whether structure matters is a permutation against a shuffled network, whose *non-rejection* is routinely written up as though the shuffle had reproduced the effect.

This paper contributes a method addressing all three (§2), an implementation that runs it per prediction rather than once per paper, and — the part we think is missing from this literature — an evaluation of the instruments themselves (§3). We demonstrate the method on cuts of a public synapse-resolution *Drosophila* connectome, a domain supplying exactly the hard case: a measured network, a literature parameter table with large gaps, and asserted transformation rules. The central contribution is an audit of evidence admission, graph-null preservation and specification propagation. The two cuts illustrate how a descriptive dependence label changes with extraction.

We organise the scientific evaluation around three research questions; reproducibility is engineering support.

* **RQ1.** Can heterogeneous published parameters be turned into computational perturbations *without* erasing their provenance or their parameter semantics, and can that discipline be stated as a checkable invariant rather than a convention?
* **RQ2.** For a given prediction, which inputs does it depend on — and is that answer a property of the prediction, or of the extract of the network it was measured on?
* **RQ3.** Which conclusions survive alternative admissible specifications, and which assumptions dominate the output's variance?

The results show a finite, checkable admission rule for RQ1; extract- and runtime-dependent labels for RQ2; and specification-dependent model-output predicates for RQ3. These findings are conditional on the current parameter table and selected cuts. The RQ1 tests check declared types, readout paths and gain vectors; they do not verify the primary assay value behind each admitted row.

## 2. Methods

### 2.1 Typed evidence propagation (RQ1)

The common failure this replaces is a pipeline that applies one transform to whatever number a source reported and gives the result one name. That erases two distinctions at once: a normalised functional response is not a fraction of occupied binding sites, and a row with no sourced number must not yield a small response at all.

Each row declares a **parameter type** and an ordered **evidence distance** between the stated source and modelled target: E0 (on-target); E1 (cross-species); E2 (related receptor); E3 (class extrapolation); E4 (unsupported). The admissible **transformation** is a total function of that pair (T20): a binding constant yields a physical occupancy only at E0 and a labelled proxy beyond it; a functional potency yields a direct engagement at E0 and a proxy beyond; anything at E4 is `not_modelled` and returns N/A. The result carries the name it earned, so a transferred number cannot be read as a measured one downstream.

Two properties distinguish this type discipline from a lookup table. First, requesting a value from an inadmissible row raises an error instead of returning a number. Second, tests check the invariant *no numeric engagement reaching an enumerated readout path may originate from a row whose (parameter type, distance) pair does not admit one*. The checks cover every shipped row and tested entry point; a companion test verifies that omitting inadmissible rows leaves the tested gain vectors unchanged, and a mutation test verifies that altering the rule table is detected. They do not check the primary assay record against each admitted numerical value, so source-to-value verification remains incomplete.

### 2.2 The extracts, and what the runtime does to them

Two committed extracts of MaleCNS v1.0 are used, streamed out of the ~1.1 GB public weight matrix on a CI runner and each under about 1 MB of JSON: **`named`**, a 1-hop neighbourhood of two seed cells (1126 nodes, 1360 edges), and **`taste_motor`**, the same seeds plus sensory types and an induced closure (1841 nodes, 19 066 edges). A saved exploratory scale record describes nested extracts of 1k, 5k, 10k, 25k, 50k cells; its larger input cuts are absent from this review package.

**The extracts are structurally very different, and the difference turns out to be load-bearing (T19).** `named` has mean degree 1.208: 85% of its edges terminate on the 4 seed cells, only 184 of 1126 nodes receive any input, and only 25% of edges leave a node that itself receives input. It is dominated by edges entering seeds, with limited recurrent connectivity within this truncated cut. `taste_motor` has mean degree 10.4, 10% of edges onto seeds and 97% of edges leaving a node with input. Composition differs too, and one class is absent from both (0 cells), so a perturbation acting only through it cannot move either readout for substrate rather than domain reasons; the full census is in T19 and §S9(v).

Two runtimes consume a gain patch: a deterministic clipped leaky rate iteration (~50 ms per evaluation of `named`) and a current-based LIF network [7] whose synaptic scale and background drive are tuned constants, not fits (§S3).

**The rate runtime row-normalises its weight matrix.** Each row of the signed matrix is divided by `max(Σ|W|, 1)` before any gain is applied, and gains then act as a presynaptic column scale. The resulting recurrent input depends on the weighted composition of a cell's presynaptic sources. This runtime convention can affect RQ2's classification; §3.3 compares it with no normalisation and a degree-corrected denominator. The sign table is reported in T21: 5 of seven magnitudes (glutamate -0.4, histamine -0.5, dopamine +0.2, serotonin +0.2, octopamine +0.2) are asserted and fixed in the gain-rule family and Sobol analysis. The transmitter-label null changes label assignments, not these magnitudes.

### 2.3 Input-dependence testing (RQ2)

The instrument we consider most transferable asks, for one `compound × concentration × circuit × readout`, how much of the real connectome a prediction needs. The same drug contrast (treated minus vehicle, both arms on the *same* graph) is measured on progressively degraded copies of the cut, which form an **information ladder**:

| Graph model | What it still knows |
|---|---|
| `erdos_renyi` | node and edge counts, the weight histogram, the transmitter census |
| `rewire_degree_preserving` | + every node's in-degree, out-degree and transmitter |
| `weight_permute` | + the real edge list (weights reshuffled) |
| `sign_permute_weight_matched` | + the real weights on the real edges, and each transmitter's share of total outgoing weight |
| the MaleCNS cut | everything |

Because a gain patch acts *through* transmitter identity, the plain label-permutation null changes both the target set and the sign assignment. It is therefore analysed separately as a **joint target-set-and-sign null**. The rank-3 rung uses a constrained shuffle holding every tracked transmitter's share of outgoing weight within 0.002 of the real graph's. Permuting labels preserves the transmitter histogram *by count* but not *by weight*: out-strength is heterogeneous, so on the `named` cut the cholinergic share of total outgoing synaptic weight is 0.619 on the real graph against 0.544 ± 0.027 across 1000 permutations (T23).

Each mode receives one of three verdicts against a margin prespecified as 5% of the vehicle readout (0.332 rate-model units on `named`): `distinguishable` when the empirical two-sided permutation probability `(k+1)/(n+1)` is at or below α; `equivalent_within_tolerance` when the test does not reject *and* the observed point gap from the null median is below the margin; `indeterminate` otherwise. The point-gap verdict is descriptive, not a formal equivalence test with a confidence bound. A **class** and **necessary information level** summarise these component verdicts. The level identifies the weakest graph model this test could not distinguish from the real cut; it does not establish that the model reproduces the effect. Non-monotone ladders are flagged and counted in §3.2.

Three further conventions are specified in §S2: a *relative* effect floor, separate planned profiles and exploratory landscapes, and a check of permutation resolution. Benjamini-Hochberg adjusts the exploratory component-test probabilities within the declared family; it does not provide a false-discovery guarantee for the derived cell classes.

### 2.4 The ablation ladder and the specification family (RQ3)

*Which layer carries the information?* Four models predict the same cell with one layer denied: **A** receptor engagement alone; **B** mechanism gains on the graph's transmitter composition only, no edges; **C** the real cut and runtime with one generic multiplier; **D** the full model. They carry different units, so they are compared by how well each reproduces the full model's *ordering* of the library, scored on the **signed** Spearman ρ because a perfect inversion reproduces nothing.

Level C uses a generic magnitude with a mechanism-derived sign, one bit per compound. A depression-only generic rule is retained as a sensitivity reference (§S1). Levels B and D are not independent models, both being functions of the same gain vector, so §3.3 reports a **matched reference distribution** saying what agreement would have been for structural reasons alone.

*Which model-output predicates depend on the gain rule?* The parameter-to-gain mapping is the least defensible part of the pipeline — a textbook shape, but an asserted functional form. We evaluate 25 gain-rule specifications (five shapes at five coefficient scales, §S1.1) and re-derive each stated model-output predicate under every member; undecidable cells count against retention and are reported separately, and the fraction is a fraction of *that family*, not a posterior probability. The topology predicates are decided at 100 permutations per specification (resolution 0.010), corrected across the run's 100 structural tests. The two thresholds are likewise conventions, so the verdict is recomputed over the full 25%, 40%, 50% × 10%, 20%, 30% grid on 10 compounds.

### 2.5 Evaluation taxonomy

Agreement with published work is worth little unless its kind is named, so we separate three. **Implementation consistency** — the same inputs give the same outputs across transports, runtimes and runs (§3.7). **Literature concordance** — the model's *ordering* agrees with a published ordering, scored per entry and never as a bare mean, since an entry ordering two items can only return ±1; where the published ordering shares a source with the library, agreement is internal consistency, and the pipeline computes that overlap from DOIs and PMIDs rather than asserting it. **Independent out-of-sample validation** — against data entering neither the library nor the model, of which there is **none** at the circuit level. The planted-cycle experiment of §3.1 checks recovery for one synthetic mechanism, not the domain model.

### 2.6 Global uncertainty and the value of information

A one-at-a-time sensitivity analysis cannot separate a factor's own effect from interactions, so uncertainty is attributed with a variance-based (Sobol') analysis over the selected factors: potency, Hill coefficient, engagement-to-gain transformation and coefficient, external drive, the cut's synapse-weight threshold, transmitter-label reassignment probability, expression weighting and a deliberately null spiking RNG seed, which the deterministic rate engine ignores. Transmitter-label reassignment does not vary the fixed sign magnitudes in T21. The design uses Saltelli cross-sampling with Jansen estimators [70], [71] and is checked against the analytic Ishigami benchmark [72].

Estimates are left unclipped, so a factor whose true index is zero can be estimated below zero. A first-order index cannot be negative, so the **largest magnitude among the negative estimates is a measured lower bound on the estimator's error**, and that — not the null factor's own draw — is the noise floor we report. For prioritisation we define a heuristic score `H_j = max(0, S_j) · Var(Y)`, conceptually motivated by information-value reasoning [75]. It ranks model-output variance under assumed ranges, not formal expected information value or biological accuracy.

### 3.1 Synthetic positive controls and permutation convergence (Fig. F16, Tables T11, T22)

The dependence procedure is checked against a **planted synthetic contrast**. A recurrent cycle of known strength is planted in a synthetic network of 250 nodes and about 1500 background edges. Its transmitter composition was chosen close to the `named` cut, but size and connectivity were not matched. The perturbation removes amplification that exists while the planted cycle is intact, so the treatment contrast depends on its wiring by construction. Strength 0 plants nothing and is the negative control. This design tests recovery for the planted mechanism, not power for all network effects.

The ladder recovered 2 of 3 planted effects at *n* = 200 with no false positive on the control. In a small grid of 6 independently generated networks per cell and permutation counts 50, 200, 1000, detection by planted strength was strength 0.25: 0.00-0.17; strength 0.5: 0.67-0.83; strength 1: 1.00-1.00; the empirical false-positive count was 0 of 18. Detection was limited at 0.25. The count was n=50: 0.61, n=200: 0.61, n=1000: 0.67 across permutation budgets. The observed full-detection strengths are 1 in this finite grid. These synthetic results motivate a sensitivity warning for weak effects; they do not establish general power or justify a universal permutation budget.

The convergence sweep (T11) separates the two quantities that permutation budget buys: a *verdict* at α = 0.05 settles from *n* = 50–400, while a quotable mid-range probability needs 25–400 draws to reach ±0.02 of its final value. The sweep re-reads prefixes of the same draws, so every row is a valid smaller sample and no extra runtime was spent producing it.

### 3.2 Dependence labels differ between the two extracts (Figs. F6, F12; Tables T6, T12, T12b, T23, T27)

**The planned profiles** (full per-mode table: T6, §S2.1). At 1000 permutations per mode (resolution 0.0010), imidacloprid's effect on the sparse `named` extract is -6.173 rate-model units and the cell is **composition-dominated**: against the declared margin of 0.332 rate-model units, rewire_degree_preserving, sign_permute_weight_matched, weight_permute null comparisons pass the descriptive point-gap rule, sign_permute remain unresolved, and the Erdős–Rényi control is distinguishable (*p* = 9.99e-04 versus 0.472 for degree-preserving rewiring). Fipronil on the same extract is the contrast — 0.900 rate-model units, **topology-dependent**, *p* = 0.006 and 0.007 for weight permutation and rewiring, reported level `wiring_with_weighted_transmitter_balance`. The weight-matched transmitter null reduces imidacloprid's gap from 2.652 to 0.236 rate-model units, changing an unresolved comparison to a point-gap pass without establishing statistical equivalence.

**Descriptive landscape.** The `named` cut has 85% of edges entering four seed cells. Over 21 compounds × 4 concentrations = 84 cells at 1000 permutations, with Benjamini-Hochberg across the 168 structural component tests and the relative effect floor applied, it gives **0 topology-dependent, 44 composition-dominated, 40 no-effect, 0 mixed** labels (uncorrected 11 / 33 / 40; on the absolute floor alone 0 / 59 / 25, with 15 cells removed by the relative floor in T12). The denser `taste_motor` extract uses 300 permutations and gives **44 / 0 / 40** among the same 84 cells; these classifications have no cell-level FDR guarantee and are conditional on each cut's nulls and runtime.

**Exploratory scale record.** The saved scale study reports 7 cuts (scale_1k, named, taste_motor, scale_5k, scale_10k, scale_25k, scale_50k; T27). The composition-dominated label appears on 1 (named), with per-rung sequences in §S2.4. The larger 5k–50k input cuts are not in this package, so those rungs cannot be independently rebuilt from the supplied data. The observed association of cut construction, density and label does not isolate recurrence as a cause; the two committed cuts also differ in composition and extraction rule. The lower permutation budgets on larger cuts (20-1000 draws) further limit comparisons.

The scale record uses decreasing permutation budgets as edge count grows (20-1000 draws; resolution 0.0010-0.0476). Comparisons between the hops-limited committed cuts and nested ranked-BFS scale cuts confound size with extraction rule. Results from the missing larger inputs are reported as imported observations, not reproduced outcomes.

**Interpretation.** The sparse `named` cut has a large incoming-star component, whereas `taste_motor` contains more edges among nodes receiving input (T19). Degree-preserving rewiring may therefore change less of the effective input pattern on `named`. This is one plausible explanation for the contrasting labels, not a causal test of recurrence. Dependence classifications must be reported with the extract and runtime used.

**Multiplicity.** The planned fipronil profile at 1 µM has component-test *p* = 0.006 at *n* = 1000. In the exploratory landscape, a corresponding adjusted component-test value is 0.062, with corrected class composition-dominated versus topology-dependent before adjustment. Benjamini-Hochberg applies to the declared structural test family; the cell class itself has no separate FDR guarantee.

The planned fipronil profile and its exploratory landscape class therefore answer different testing questions; a nominal result in the profile does not override the adjusted landscape label.

**What the class label does not say.** The ladder is **non-monotone** in 0 of 84 cells on `named` and 1 of 84 on `taste_motor`, because adjacent rungs destroy different things. The level is the lowest-ranked degradation that passes the declared test and point-gap rule, not a monotone information threshold. A `composition-dominated` label also does not mean the null reproduces the effect: across `named` mode verdicts, 316 pass the descriptive point-gap rule, 44 are unresolved and 60 are distinguishable.

### 3.3 Which pipeline layer carries the information, and what agreement would have been anyway (Fig. F13, Tables T13, T13b, T24, T25)

Under the current library, receptor engagement alone has signed rank correlation ρ -0.579 to 0.095 with the full-model ordering. The lowest-correlation level is yes across the reported concentrations (10 nM: A_receptor_only (0.095); 100 nM: A_receptor_only (-0.519); 1 µM: A_receptor_only (-0.564); 10 µM: A_receptor_only (-0.579)); under the depression-only level-C reference, the lowest level varies (10 nM: C_topology_only; 100 nM: A_receptor_only; 1 µM: A_receptor_only; 10 µM: A_receptor_only). This comparison is conditional on the library and generic rule.

**Ablation reference.** A depression-only generic multiplier cannot represent disinhibition. The direction-aware rule uses the same generic magnitude with a mechanism-derived sign, and its topology-only rank correlation at 1 µM is 0.968 versus 0.161 under the depression-only reference. The difference shows that the generic rule affects the rank comparison.

**The composition-versus-full correlation does not by itself establish compound-level information.** It is 0.921 at 1 µM and 0.826 after dropping compounds on the 0.05 gain floor, so it is not solely a tie artefact. Levels B and D both use the same gain vector. Pharmacology-free pseudo-compounds matched to the shipped gain shapes give a reference median of 0.847 over 50 draws (5th–95th percentile 0.676 to 0.953). Permuting compound labels moves B–D pairs together and leaves the observed correlation 0.921.

**Runtime normalisation changes the agreement.** The correlation is 0.921 under the shipped normalisation and 0.935 with none, but 0.551 under a degree-corrected denominator at 1 µM and -0.583 at 10 nM. Agreement holds under row normalisation and without normalisation but weakens under degree correction, so it depends on the runtime's normalisation. A sign disagreement between the two levels moves it by at most 0.086 and so is not what produces the agreement (§S9(i)).

### 3.4 Gain-rule sensitivity of model-output predicates (Fig. F14, Tables T14, T14b, T15)

**Specification test conditions.** The topology predicates use 100 shuffles per specification (resolution 0.010), and the gain specification is passed to the null engine. These conditions allow the empirical test to reach α = 0.05 and ensure the intended mapping is evaluated. The reported retention fractions are conditional on this implementation and the declared 25-member family.

Across 25 gain-rule specifications, C3 and C4 are retained in 25 and 25 cases. These C1–C7 conclusions are predicates over model outputs and the chosen null procedure, not robust biological conclusions. The transmitter sign magnitudes and transmitter-defined assignment are fixed across the family. For C3, 17 of the retained cases meet the descriptive point-gap criterion and 8 are indeterminate. Benjamini-Hochberg adjusts the 100 component tests in the run; it does not guarantee a false-discovery rate for predicate retention.

* The domain's most quotable claim — that the agonist suppresses activity — is retained by only 15 and **reversed** by all 10 monotone specifications: the same compound at the same engagement takes the network from 6.631 to 10.1 rate-model units (+52%) instead of from 6.631 to 0.458 rate-model units, with `g_ach` at 1.396 against 0.050. The direction is a property of one asserted term, not of the integration.
* The buffering predicate is retained in 18 of 25 cases and undecidable in 7. Across 6 monotone specifications with a defined index, the mean gap spans -0.199 to -1.734 log₁₀ units; 3 buffer less than the shipped rule (linear@1.50x, saturating@1.25x, saturating@1.50x).
* The matching amplification claim is weakest at 18 of 25. Retained by every specification: C2_rdl_disinhibition, C3_imidacloprid_topology_not_distinguishable, C4_fipronil_topology_exceeds, C7_map_bitter_veto.

The threshold grid makes the same point about conventions rather than transformations: the split is **not** stable (`stable = no`), buffering holding in 9 of 9 cells (-0.362 to -1.224 log₁₀ units) and amplification in 7 of 9, flipping at the strictest corner (circuit_frac=0.40,vert_limit=0.10, circuit_frac=0.50,vert_limit=0.10, gap -0.154), so ranges are quoted and never the point estimate. Two tables that appear to disagree in fact score different sets — T15 the 10 compounds of two mechanism classes, T8 the whole library — so acetylcholine is scored in one and outside the other's scope.

### 3.5 Variance attribution, and what to measure next (Fig. F15, Tables T16, T17)

The Sobol' analysis uses 11 264 model evaluations at n_base = 1024 and yields Var(Y) = 3.149 in squared rate-model units. Bootstrap first-order intervals exclude zero for 2 of 9 factors (gain_transform, weight_threshold), including the engagement-to-gain transformation (S1 0.410, ST 0.626) and cut weight threshold (S1 0.294, ST 0.542). Other factors are unresolved at this sample size (drive, expression, gain_coef, hill_n, lif_seed, potency, transmitter). The first-order estimate for external drive is 0.019 with interval (-0.072, +0.112), and the negative-estimate noise diagnostic is 0.046, driven by gain_coef rather than the deliberately null factor (estimate -0.007). Estimated interaction shares are 0.344 raw and 0.272 after clipping negative estimates. Ishigami estimates are 0.3163, 0.4495, 0.0072 versus analytic values 0.3139, 0.4424, 0.0000 (maximum absolute error 0.007). These numerical diagnostics do not validate the biological model.

The author-defined variance-priority heuristic ranks **gain_transform** first (1.290 of 3.149 squared rate-model units). A direct assay of the response-versus-engagement curve at a known synapse (calibration of receptor engagement against synaptic gain) could constrain this factor. **weight_threshold** ranks second (0.925 squared rate-model units) and could be constrained by re-analysis of synapse-confidence strata. These rankings are conditional on assumed factor ranges, not formal expected values of information or evidence of biological importance.

### 3.6 What the refusal rule actually does (Fig. F11, Tables T10, T20)

The type system changes which rows enter numerical predictions. Of 102 library rows, 63 are withheld and return N/A. The admitted categories (T20) contain physical binding (1), binding proxy (1), direct functional engagement (6) and transferred functional engagement (31) rows, assigned by declared type and distance. The binding model row is imidacloprid at insect_nAChR_native_dmel (Kd 2e-09 M) [76]; imidacloprid at insect_nAChR_beta1 (Kd 8.3e-11 M) is a transferred proxy. These admission categories do not independently verify every numeric source-value link. ## 4. Discussion

**Dependence interpretation.** The same procedure classifies 44 of 84 cells as composition-dominated on `named` and 0 of 84 on `taste_motor`, under their declared floors and test families. This is evidence that a dependence label is conditional on the cut, its construction and the runtime. The imported scale record adds descriptive observations across 7 cuts, but missing large-cut inputs and changing permutation budgets prevent a separate reproduction of the complete scale ladder. The observed structural differences suggest hypotheses about recurrence; they do not identify recurrence as the cause of the label change.

*Second*, typing the evidence changes results rather than documentation: refusing inadmissible rows removed a class of small, plausible, invented numbers no reader could have told apart from measurements, and grading a source's distance demoted a cross-species constant to a labelled proxy without changing its value. Stated as an invariant and checked exhaustively, this is a property of the pipeline rather than a convention its authors intend to follow.

*Third*, two of the instruments were themselves broken in ways that flattered the conclusions, and both were found by pointing the instruments inward: a null that moved the quantity it claimed to preserve exactly, and a specification family whose alternatives never reached the engine its predicates ran on, so a uniform robustness rate was guaranteed by construction. Both failures share a signature worth naming — **a test whose result was determined by its own implementation rather than by the data** — and both were invisible to determinism checks, because a record can be perfectly reproducible and still be produced by a test that could not have returned another answer. The specification family and the variance decomposition then converge on one weak point: the direction of the headline effect is set by an asserted functional form, which is also the largest resolved factor in the variance budget and the top-ranked measurement.

**Encoded assumptions versus generated observations.** An audit of the dependency chain behind one readout returns 9 links (T18): 1 link measures the simulated system, 1 reuses a measurement of something else, 4 are asserted model choices and 3 are computational links. This is a trace for one readout, not a partition of biological evidence quality.

**Relation to adjacent work.** Similar model-output associations in receptor-map network models [68], [69] motivate comparison of normalisation and spatial aggregation. The current experiments do not establish a shared mechanism or a biological correspondence between those domains.

**What the pipeline cannot support**, and these limits are themselves computing results about what such a pipeline can establish. It cannot predict a dose–response in an animal: with no pharmacokinetics available, the free concentration is an *input*, not a derived quantity. It cannot support a cross-species safety claim, nor a subunit-level claim where the sources used hybrid constructs. It cannot support a general statement about whether perturbation on networks of this kind needs topology — only a statement per extract with that extract's structure reported. And it cannot produce a live-animal result, which no code path may write.

**Model-specific caveats** are detailed in §S9: fixed asserted transmitter sign magnitudes, load-bearing row normalisation, perturbations applied across transmitter-defined rather than receptor-defined synapses, truncated extracts with missing inputs, and only qualitative direction agreement between the two runtimes. The gain-rule family does not vary the sign magnitudes or transmitter assignment model.

**Prospective hypotheses.** The hypotheses in §S5 are software predictions with no live result. They are not preregistered; a mutable repository is not a registry. The direction of two readouts changes within the tested specification family, as stated beside those hypotheses.

## 5. Conclusion

This study implements typed admission of parameter rows, graph-degradation comparisons, ablation references and gain-rule sensitivity checks for two cuts of MaleCNS v1.0. It finds that some model-output directions depend on the asserted gain rule and that descriptive dependence labels differ between the two cuts. The source-value audit, missing inputs for larger saved scale rungs and absent circuit-level experimental validation limit biological interpretation. The graph-null and point-gap results are conditional on the declared extract, runtime, margins and component-test family.

Next steps are direct calibration of the engagement-to-gain transformation, verification of the remaining source-to-parameter links, reconstruction-confidence analyses, reproducible larger-cut tests and an independent circuit-level assay. Until these are available, the results are a methodological case study and software-derived predictions.
