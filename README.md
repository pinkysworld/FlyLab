# FlyLab

A **virtual pharmacology bench** on the public **MaleCNS v1.0** connectome of the adult male *Drosophila melanogaster* brain and ventral nerve cord.

One compound, one concentration, two panels — insect circuit and vertebrate receptor panel — and one notebook JSON with its provenance attached.

Two things make it more than a simulator: the pharmacological evidence is **typed**, so a receptor with no sourced value returns N/A instead of a plausible number; and every prediction can be asked **what it depends on** — the weakest degraded version of the connectome that still reproduces it.

https://github.com/pinkysworld/FlyLab

**Agents / next model:** read [`HANDOFF.md`](HANDOFF.md), then [`docs/RESEARCH_MAP.md`](docs/RESEARCH_MAP.md).

## What it is

```
compound + concentration
        → typed engagement on insect receptors ─┐      → vertebrate panel at the same dose
          (Kd/Ki → occupancy, EC50/IC50 →       ↓              (scored, never simulated)
           engagement, nothing → N/A)
                             mechanism table → gain patch
                                              ↓
              named MaleCNS cells (MN9, DNp01, labellar GRNs)
                                              ↓
                  rate or LIF runtime → readouts → notebook JSON
                                              ↓
        dependence · ablation · specification robustness · uncertainty budget
```

It is **not** a new connectome, not GLP toxicology, not a 166 000-cell spiking product, and not a source of live-animal results. The `live_lab` field of every notebook is `null` unless a human imports a real table.

## Install

```bash
git clone https://github.com/pinkysworld/FlyLab
cd FlyLab
python -m pip install -e ".[dev,viz]"
python -m pytest -q
```

Python 3.11+. Windows, macOS and Linux; no build step and no Electron.

## Quickstart

**Command line**

```bash
flylab list-drugs                                     # the 21-compound library
flylab occupancy imidacloprid --conc 1e-6             # typed engagement, both species
flylab compare imidacloprid fipronil --conc 1e-6
flylab assay-subgraph --compound imidacloprid --conc 1e-6    # rate model, MN9/DNp01 cut
flylab assay-spiking  --compound fipronil     --conc 1e-6    # Shiu-style LIF
flylab assay-taste-map --compound fipronil --conc 1e-6       # map-extracted GRN → MN9
flylab ic50 --compound imidacloprid                   # the model's own circuit midpoint
flylab null-panel --compound fipronil                 # four connectome null models
flylab selectivity --conc 1e-6                        # receptor vs circuit selectivity
flylab predictions                                    # prospective H1–H7
flylab graph info --graph taste_motor
flylab experiment example > design.yaml && flylab experiment run design.yaml
flylab reproduce-paper                                # prints how to run the paper pipeline
```

**Local server**

```bash
flylab serve          # http://127.0.0.1:8765
```

`flylab reproduce-paper` deliberately only prints the recipe: the pipeline takes options and writes into `papers/`, so it is driven by the script (below) rather than by a CLI shim that cannot pass flags.

**In the browser, with nothing installed**

The same wheel runs on Pyodide and is published as a static site; see [`docs/PAGES.md`](docs/PAGES.md). The browser and the server answer the same routes with numerically identical results.

## The panels

| Panel | What it shows |
|---|---|
| Dose | compound, concentration, ladder |
| Scorecard | insect vs vertebrate engagement and the selectivity block, with evidence types and tiers |
| Curves | engagement vs concentration, circuit readout vs concentration with a CI band, the model's circuit midpoint |
| Circuit | the neighbourhood graph, nodes coloured by transmitter and sized by rate, before/after |
| Spikes | LIF raster and PSTH for named cells |
| Exposure | *C(t)* and engagement(t) for a dose and route |
| Experiment | compounds × concentrations × replicates, results grid, CSV export |
| Notebook | the JSON, its warnings, export, and import of a `live_lab` table |

## Results at a glance

Every number below is regenerated by `python scripts/reproduce_paper.py` and stored keyed in `papers/results.json`. All of it is model behaviour; none of it was measured in a fly.

| Claim | Value |
|---|---|
| Typed library | 101 rows / 21 compounds / 14 receptor keys: 34 EC50, 10 IC50, **1 Kd**, 56 not modelled (return N/A) |
| Imidacloprid at 1 µM, insect nAChR vs vertebrate α4β2 engagement | 0.991 vs 0.091 (500× potency ratio) |
| Fipronil at 1 µM, insect RDL vs vertebrate GABA-A engagement | 0.985 vs 0.476 (37× — after a library correction) |
| Labellar GRN types present in MaleCNS v1.0 | all 16 `LB*` types; 34 sweet + 38 bitter seed cells |
| Map-based bitter veto of sugar-driven MN9, vehicle → under fipronil | 0.00 → 0.41 (rate), 0.16 (LIF) |
| **Imidacloprid, mean rate, vs 4 degraded graphs (n = 1000)** | **composition-dominated**: p = 0.275 / 0.586 / 0.472; a graph knowing only degrees and transmitters reproduces it |
| **Fipronil, same test** | **topology-dependent**: p = 0.0060 (weight), 0.0070 (degree) |
| **Library landscape, 21 × 4 cells** | 20 topology-dependent (exactly the chloride-channel blockers), 51 composition-dominated, 13 no-effect |
| Bitter-veto arm, n = 300 | a properly powered **negative**: p = 0.42 / 0.88 / 0.20 / 0.24, all \|z\| < 0.25 |
| **Ablation ladder** | composition-only reproduces the full ordering (ρ 0.906–0.989); receptor-only is backwards (ρ −0.05 to −0.51); topology-only is worst (ρ 0.24) |
| **Specification robustness (25 gain rules)** | "nicotinic agonist suppresses" 15/25 and **reversed by all 10 monotone rules**; RDL disinhibition and both topology conclusions 25/25 |
| **Uncertainty budget (Sobol', 11 264 evaluations)** | `gain_transform` S1 0.410, `weight_threshold` 0.294, drive 0.019, rest at the ±0.007 noise floor |
| **Value of information** | resolve `gain_transform` (1.29 of 3.149 Hz²) by calibrating engagement against synaptic gain; `weight_threshold` (0.925 Hz²) needs **no experiment** |
| Literature concordance vs published orderings | mean Spearman ρ = 0.88, 2 inversions recorded and explained; **no independent out-of-sample circuit validation exists** |

The headline negatives are deliberate and are the reason the tool exists: most of what it predicts does not need the connectome, and its most quotable circuit result is a property of one asserted gain rule rather than of the pharmacology–connectome integration.

## Data provenance

| Source | How it is used | Committed? |
|---|---|---|
| MaleCNS v1.0 flat connectome (CC-BY 4.0) | netlist; cut on GitHub Actions by `flylab/maps/extract.py` | no — only two derived JSON cuts in `data/derived/` |
| MaleCNS annotations + transmitters | census, named cells, gustatory seeds | no — a small committed census fallback instead |
| `flylab/pharm/library.yaml` | schema v3: parameter type, value, Hill *n*, direction, **source relation**, species, source, evidence tier per receptor row | yes, with a SHA-256 in every notebook |
| `data/literature/` (six YAML datasets) | resistance alleles, published rank orders, expression, mixtures, fly PK, behavioural baselines | yes — every value carries a DOI or PMID |

The 1.1 GB weight matrix is never committed and never needed to reproduce the paper.

## The honesty rules

These are not style preferences; PRs that break them are rejected.

1. **No invented constants, enforced by types.** Every receptor row has a `source`, an `evidence_tier`, a `param_type` and a `relation`. A missing number stays missing: an unsupported row returns **N/A** and is excluded from every numeric result, and asking for a number anyway raises `EvidenceTypeError`. Say *engagement* for an EC50/IC50-derived Hill value; *occupancy* is reserved for the one row with a measured Kd.
2. **Two panels, one dose.** The vertebrate panel is scored at the same free concentration and never patches a circuit.
3. **Warnings ship.** Reduced-circuit, hops-limited, predicted-transmitter and teaching-EC50 warnings live in the exported notebook, not in a log line.
4. **At most one fitted parameter, later.** Nothing is fitted to animal data. Hill fits of the model's own curves are labelled `model_derived`. The uncertainty budget names the one worth fitting: the engagement→gain transformation.
5. **No live-animal numbers, ever, from code.** `live_lab` stays `null` until a human imports a table. `protocols/` holds unexecuted drafts.
6. **Report contradictions, do not silence them.** `data/literature/README.md` lists ten places where the literature disagrees with the library, and `flylab/validation/rank.py` records two ordering inversions rather than fixing them.
7. **State what a prediction depends on.** No claim that "the connectome matters" without naming the compound, the concentration, the readout and the permutation p.

## Reproducing the paper

```bash
python scripts/reproduce_paper.py            # ~8-10 min: 15 figures, 21 tables, results.json
python scripts/reproduce_paper.py --fast     # ~2 min, fewer permutations and replicates
python scripts/reproduce_paper.py --only dependence --outdir /tmp/x
python scripts/reproduce_paper.py --list
```

Outputs land in `papers/figures/`, `papers/tables/` and `papers/results.json`, and both `papers/IJRC_FlyLab_draft.md` and `papers/SUPPLEMENT.md` are re-rendered from their templates so no number can drift between the code and the prose. Nothing is downloaded. `--fast` is a sanity check, not the paper: it changes statistical effort only, and a test refuses a committed `results.json` that came from one.

## Contributing

- Read `HANDOFF.md` and `docs/RESEARCH_MAP.md` first. A PR that only adds a prettier fly viewer will be rejected.
- Changing an EC50 requires a new `source` string and the matching `evidence_tier`. Changing a gain rule requires updating `flylab/pharm/mechanisms.py` (the single source of truth), its docstring rationale and `T2`.
- Do not commit `*.feather`, do not add hops to a neighbourhood cut (raise the weight floor instead), and do not hand-edit `data/derived/*.json`.
- `python -m pytest -q` must stay green; `pytest -m slow` additionally runs the minutes-long end-to-end checks.
- Cite the connectome papers before this software (`CITATION.cff`).
