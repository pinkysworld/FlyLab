# Novelty (keep this short in the paper)

Existing virtual rats (RatCVS, Virtual Rat Web) model organs without neurons.

Existing fly connectome runtimes (flypoke, MaleCNS LIF ports, meme sims) model neurons without ligand–receptor occupancy.

FlyLab is the missing object: **the same compound, two scorecards, one notebook** — insect circuit + vertebrate receptor panel — with a live-assay slot.

If a PR only adds a prettier fly viewer, reject it.
