Across them, 72 distinct DOIs resolved through [Crossref's registered-work API](https://api.crossref.org/works/10.1016%2Fj.cell.2026.08.015); registered titles, first authors, publication years, and volume/issue/pages or article numbers match the cited records. All 48 distinct listed PMIDs resolved through [NIH PubMed](https://pubmed.ncbi.nlm.nih.gov/) to the cited articles. Bibliographic existence is **not** proof that each paper supports a numerical library value or every scientific inference.

**Claim-support and verification limits.** Shiu *et al.* [main 8/source 7] supports a connectome-based LIF model of **central-brain** feeding/grooming circuits and says all but one model parameter came from previous modelling/electrophysiology or the connectome; it is not a whole-MaleCNS or pharmacology validation ([Nature article](https://www.nature.com/articles/s41586-024-07763-9)). Mindlin *et al.* [main 11/source 68] reports that maximum simulated perturbation distance correlated with the **mean density of normalized receptor maps**, while a local node-strength comparison did not show the same result. This does not prove location never matters in receptor-weighted network models ([Communications Biology article](https://www.nature.com/articles/s42003-024-06852-9)). The provenance and interpretation of each numeric library row remain a separate row-by-row scientific audit; checking bibliography metadata cannot validate an inferred transfer, a binding-to-effect conversion, or a concentration value.
