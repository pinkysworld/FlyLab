# Live *Drosophila* protocols

These pages are for Gate 5. They are written so a fly room can pair a vial assay with a FlyLab notebook JSON.

Institutional ethics and local rules win. Adult *Drosophila* work is usually outside vertebrate animal-act licensing in Germany, but confirm with the host lab.
